Frequently Asked Questions

How do I add a website to block?

Click the ZFocus icon in your browser toolbar, then click "Open Settings". Go to the "Websites" tab and click "Add New Group". Enter a name for the group, add the websites you want to block, and set your time limits.

How does the time limit work?

When you set a time limit (e.g., 5 minutes per hour), ZFocus tracks how long you spend on blocked sites. Once you exceed the limit within an hour, the site will be blocked until the next hour starts. The timer resets every hour.

What happens when time runs out?

You can choose one of two actions: Close Tab (closes the current tab) or Redirect (sends you to a different URL, like your todo app). You can set a custom redirect URL for each website group.

Can I pause blocking temporarily?

Yes! Click the ZFocus popup and use the pause button. You can pause for 3, 5, 10, 15, 30, or 60 minutes. Note: If Hard Lock Mode is enabled, pausing is disabled during work hours.

What is "Count Only Active Tab"?

When enabled, ZFocus only counts time when the tab is active (visible and in focus). This is useful if you want to allow background music from YouTube while still limiting active browsing time.

How do schedules work?

Each website group can have its own schedule. You can set start/end times and which days the blocking applies. Outside of scheduled hours, you can browse freely (unless you disable "Allow Outside Hours").

What are Keywords in URL?

This premium feature lets you block any URL containing specific keywords. For example, blocking the keyword "game" will block any website with "game" in the URL, not just the sites in your URL list.

How do I sync settings across devices?

ZFocus uses Chrome's built-in sync. If you're signed into Chrome on multiple devices, your settings will automatically sync. Historical statistics are stored locally and won't sync.

Extension Not Working?
  1. Make sure the extension is enabled in chrome://extensions
  2. Try reloading the page you're trying to block
  3. Check if the website is in your blocked list and the schedule is active
  4. Disable and re-enable the extension
  5. If issues persist, try removing and reinstalling the extension
